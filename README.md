# Dictionary App

A simple browser-based dictionary that looks up English words and displays their pronunciation, audio, definitions, and synonyms.

## Run locally

Open `index.html` in a web browser. The app uses the [Free Dictionary API](https://dictionaryapi.dev/), so an internet connection is required to search for words.

## Files

- `index.html` — Page structure and form.
- `style.css` — Page styling.
- `index.js` — Dictionary API requests and result rendering.

## Usage

Enter an English word in the search field and select **Search**. If the word is found, the page displays the available definitions and pronunciation. Audio and synonyms appear when the API provides them.
